# Penium Torrent Web

Браузерный WebTorrent-клиент: добавление magnet-ссылки или файла .torrent, просмотр прогресса и упаковка полученных файлов в ZIP.

## Запуск
Включи GitHub Pages в Settings → Pages, выбрав ветку main и корень репозитория.

## Ограничения
- WebTorrent в браузере использует WebRTC. Обычные BitTorrent-пиры без WebRTC недоступны.
- Для соединения нужны WebRTC-совместимые трекеры и активные пиры.
- ZIP собирается в памяти браузера; большие раздачи могут потребовать много оперативной памяти.
- Используй только материалы, которые разрешено скачивать и распространять.

Библиотеки подключаются с jsDelivr: WebTorrent 2.5.19 и JSZip 3.10.1.
